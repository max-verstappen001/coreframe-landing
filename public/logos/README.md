# Partner logos

Drop official partner logo files here, then set the matching `logo` path in
`PARTNERS` inside `app/HomeClient.tsx` (e.g. `logo: "/logos/blackrock.svg"`).

Until a `logo` is set, the strip renders a clean typographic wordmark as a
placeholder.

Expected files (grayscale/monochrome SVG or transparent PNG works best):

- `blackrock.svg`
- `kemin.svg`
- `marginx.svg`
- `vprc.svg`  ← confirm which VPRC this is before adding
